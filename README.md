# kc109-tracker

Трекер задач сотрудников по п.2 Плана: анализ КЦ «109» Акмолинской области и оценка соответствия стандартам.

Страница: https://ren4115.github.io/kc109-tracker/

Один файл `index.html` без сборки. Данные хранятся в браузере каждого пользователя (localStorage); выгрузка — кнопкой «Скачать данные (JSON)».
